# NextStepAI

NextStepAI is a responsive web application that helps formerly incarcerated individuals organize their next steps after returning to the community. A short assessment produces a personalized 30-day action plan focused on employment, housing, transportation, identification, training, wellness, and other support needs.

## Why I chose this project

Reentry can involve several urgent needs at the same time. I wanted to make the process feel less overwhelming by turning a person's answers into a short, prioritized checklist.

## Features

- Guided reentry-needs assessment
- Personalized, prioritized action plan
- Employment, housing, transportation, documentation, and wellness guidance
- Print-friendly results
- Mobile-friendly design
- No storage of personal information

## Technologies

HTML, CSS, JavaScript, GitHub, and GitHub Pages.

## How it works

The application uses decision-based recommendation logic. Foundational needs, such as identification and urgent housing, are placed before longer-term goals. Recommendations are then added based on the user's main goal and selected support needs. All processing happens in the browser.

## What I learned

I practiced organizing an application into separate HTML, CSS, and JavaScript files. I also learned how form validation, DOM updates, responsive styling, conditional logic, and GitHub workflows work together.

## Future improvements

I would like to add a verified local-resource directory, optional progress tracking, additional accessibility testing, and a secure AI service that can explain recommendations in more detail.

> This tool provides general guidance and is not a replacement for legal, clinical, or case-management services.
